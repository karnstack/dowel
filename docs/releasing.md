# Releasing

Changesets owns package versions and publishing through the version PR.

Until Sourcetown completes Dowel's first production integration, every
changeset for `@karnstack/dowel` uses `patch`. These releases remain on the
`0.0.x` line while the component API is being proven in a real product.

Sourcetown's first working integration is the explicit `0.1.0` milestone. Use a
`minor` changeset for that release. Later version policy will be decided from
real adoption rather than component count.
